# Actividad 16 - School System

## Descripcion
Pagina web de un sistema escolar creada con HTML.

## Contenido
- Encabezado con logotipo.
- Menu de navegacion.
- Formulario de registro de alumnos.
- Tabla de alumnos.
- Resumen de estudiantes.
- Pie de pagina.

## Tecnologias utilizadas
- HTML5
- Linux Mint
- Vim
- Git y GitHub

## Objetivo
Aprender a crear y organizar la estructura de una pagina web utilizando HTML.

## Nota
Esta es la primera version del proyecto.
El formulario aun no guarda informacion porque
la actividad consiste solamente en crear la estructura HTML.
